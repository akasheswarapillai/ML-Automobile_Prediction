# Auto MPG Prediction 🚗

## Project Overview

A machine learning regression project that predicts vehicle **Miles Per Gallon (MPG)** based on automobile characteristics. The project covers data analysis, preprocessing, visualization, model building, and evaluation.

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Dataset

The dataset contains automobile specifications such as **cylinders, displacement, horsepower, weight, acceleration, model year, and origin**, with MPG as the target variable.

## Methodology

1. Data loading and exploration
2. Data cleaning and preprocessing
3. Exploratory data analysis and visualization
4. Feature selection
5. Train-test splitting
6. Regression model building
7. Model evaluation using **MSE and R²**

## Results

The **All Features Linear Regression model** achieved the best performance with an **R² score of 0.81** on the test data.
